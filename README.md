## This is a chrome extension build to track your friends' solutions to a particular codeforces problem. Be it your friends or your favourite Grandmasters, use this extension to view their solutions for a codeforces problem.

## Update : Version 2.1

Now, you can toggle the extension On/Off from the extension page itself. Also, you now get the most recent AC submission of the friend instead of the most recent submission(AC/WA/etc) of the friend if the friend has atleast one AC solution. Otherwise, it will show the most recent solution as fallback.
